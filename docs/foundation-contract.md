# Foundation integration contract

This records the foundation work unit under AGENTS.md, started 2026-09-07 and integrated on 2026-09-08. It is a design/ownership reference; IMPLEMENTATION.md is the current status. The user explicitly requested parallel agents. Root updates the progress ledger and shared packaging.

## Config owner
`backend/config.py`, `tests/test_config.py`. Implement Settings (data_dir Path, frontend_dir Path, secure_cookies bool, allow_cidrs tuple[str], allowed_origins tuple[str], session_hours int default 12, max_request_bytes int default 2MiB) with `Settings.from_env(data_dir: Path|None=None)`. Default frontend_dir is repo/frontend; default secure_cookies is True (root tests explicitly False or https). Default allowed_origins empty means exact request base origin only, no proxy header trust. Environment uses INFERENCE_* names. Vault APIs as AGENTS, atomic writes, safe key creation, missing/corrupt key fails closed with existing ciphertext. No plaintext values from list. `use_instance(instance)` ContextVar convenience plus `get_instance()` raising if none. Owner tests interpolation, concurrent context reset, vault restart/tamper/key loss/atomic behavior and permissions.

## Database owner
`backend/database.py`, `tests/test_database.py`. Database(path), async open/close/fetchone/fetchall/execute/backup and asynccontextmanager transaction yielding Transaction with same query methods. Lock whole transactions; cancellation rollback must finish before releasing lock. `execute` returns lastrowid; Transaction execute same. Dict rows. Numbered migrations, WAL, foreign keys, busy timeout 5000ms, no import-time I/O. Baseline original schema plus users, recovery_codes, audit_events, documents now. Preserve existing baseline tables and fields; span uniqueness includes instance_id. Future module-specific schema can be added by later numbered migrations; do not invent their entire schemas before interfaces settled.

Shared auth schema (root will consume these EXACT names):
- users(username TEXT PRIMARY KEY, password_hash TEXT NOT NULL, role TEXT CHECK role IN viewer/operator/admin, disabled INTEGER DEFAULT 0, totp_secret_enc TEXT, totp_pending_enc TEXT, totp_last_counter INTEGER DEFAULT -1, created_at TEXT default UTC datetime).
- auth_sessions: baseline fields, plus csrf_secret TEXT NOT NULL DEFAULT ''. UTC ISO timestamps are stored as UTC +00:00; root parses ISO.
- recovery_codes(username TEXT REFERENCES users(username) ON DELETE CASCADE, code_hash TEXT, PRIMARY KEY(username,code_hash)).
- audit_events(id INTEGER PRIMARY KEY AUTOINCREMENT, actor TEXT NOT NULL, action TEXT NOT NULL, target TEXT NOT NULL, details_json TEXT NOT NULL DEFAULT '{}', outcome TEXT NOT NULL DEFAULT 'success', occurred_at TEXT NOT NULL default UTC datetime).
- documents(key TEXT PRIMARY KEY,value_json TEXT NOT NULL,updated_at TEXT NOT NULL default UTC datetime).
Support Database.open idempotently and backup into a fresh destination via SQLite backup API. backup must not overwrite live DB or existing backup silently. Original legacy database upgrades should preserve original rows, validate malformed/newer schema rather than resetting.

## Network owner
`backend/net.py`, `tests/test_net.py`. `allowed_ip(address: str, allow_cidrs: tuple[str,...]=())->bool`; `validate_url(url: str)->httpx.URL` (http/https, no userinfo, no malformed hostname/port); `create_http_client(allow_cidrs=())->httpx.AsyncClient`. Client no redirects, trust_env=False, TLS verified, pooled bounded connections/timeouts, response limits callable helper if helpful. Need pin DNS validation to actual connection using supported httpcore backend wrapper/transport; preserving SNI/Host is mandatory. Reject metadata/linklocal/multicast/unspecified/reserved even with broad allow CIDRs; private/loopback only explicit allowlist. Normalize IPv4-mapped IPv6. Resolve all A/AAAA and reject a mixed forbidden answer; don't resolve twice. Tests use deterministic fake resolver/network boundaries, not Internet. Discuss transport constraints with root, do not quietly return plain unsafe httpx client.

## Root integration/auth owner
`backend/main.py`, `backend/auth_gate.py`, `backend/audit.py`, `backend/ratelimit.py`, `backend/websocket.py`, `backend/modules/__init__.py`, auth/admin module directories, tests/test_auth.py/tests/test_app.py, packaging/docs. create_app(data_dir=None, settings=None) permits test settings injection. Central middleware protects /api except setup/login/status and future explicitly machine-authenticated OTLP. API errors JSON detail/code. Security dependencies must also enforce RBAC for service callers. Tests use actual database and vault, TestClient with https://testserver and Secure cookies. First-run setup browser bootstrap must be restricted to loopback unless explicit local bootstrap token; root tests use supplied setting/token or an explicitly loopback test client address. State-changing requests with a browser Origin require exact permitted origin, missing Origin allowed for explicit nonbrowser API clients using session-bound CSRF; document this distinction. Cookie helpers own CSRF mint/validate and session expiry/revocation. App lifecycle opens DB, vault, egress client, rate limiter, authenticated notification hub, and closes all. Registration discovery validates trusted local manifests, duplicate IDs/prefixes/api versions and optional module lifespan hooks. No incomplete/fake routers.
