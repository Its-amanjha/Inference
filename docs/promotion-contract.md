# Credential and promotion implementation contract

Full scope: AGENTS.md. This unit adds explicit credential mapping/schema/provisioning and stale-safe inactive workflow deployment, separate activation and reconciliation. No external writes during development tests.

## Ownership and persistence

Root owns database migration, shared n8n client, n8n_promote orchestration/router, integration tests and docs. Credential worker owns only backend/modules/n8n_credentials/ and tests/test_credentials.py. Transformation worker owns only backend/modules/n8n_promote/transform.py and tests/test_promotion_transform.py.

Schema version 3 (root): credential_mappings(key TEXT PK, source_instance_id TEXT NOT NULL, target_instance_id TEXT NOT NULL, source_credential_id TEXT NOT NULL, target_credential_id TEXT NOT NULL, credential_type TEXT NOT NULL, target_name TEXT NOT NULL). workflow_mappings(key TEXT PK, source_instance_id TEXT NOT NULL,target_instance_id TEXT NOT NULL,source_workflow_id TEXT NOT NULL,target_workflow_id TEXT NOT NULL). Mapping key is SHA256 canonical JSON array [source_instance_id,target_instance_id,source_resource_id]. promotion_runs(id TEXT PK,actor TEXT NOT NULL,preview_id TEXT NOT NULL,idempotency_key TEXT NOT NULL UNIQUE,status TEXT NOT NULL,state_enc TEXT NOT NULL,created_at TEXT DEFAULT CURRENT_TIMESTAMP,updated_at TEXT DEFAULT CURRENT_TIMESTAMP). Previews in documents, encrypted payload. Never store plaintext workflow snapshots/secret values in audit or progress.

## Credential worker interface

service.py exports mapping_key(source,target,resource)->str; async discover(request,instance_id)->dict {supported:bool,data:[{id,name,type}],diagnostics:[{code,message}]} with bounded pagination, no secret fields. Unsupported discovery is explicit (403/404), authentication/transport failures must not masquerade as empty success. async schema(request,instance_id,credential_type)->dict reads /credentials/schema/{type}. async provision(request,instance_id,credential_type,name,reference)->dict {id,name,type}, admin only, resolves a vault reference to a dict and validates via installed jsonschema before POST /credentials. Never expose raw secret response data; mutation outcome unknown if malformed response. Caller persists intent/outcomes; do not retry.

Routes prefix /api/n8n_credentials: GET /?instance_id, GET /schema/{type}?instance_id, GET /mappings?source_instance_id&target_instance_id, PUT /mappings JSON {source_instance_id,target_instance_id,source_credential_id,target_credential_id,credential_type,target_name}, DELETE /mappings/{key}. Admin-only all. Mapping persistence after validation/recheck current role; no automatic match by name. Explicit mapping accepted if discovery unsupported, diagnostics say verification unavailable. Do not implement standalone provision endpoint (promotion journals side effects).

Root extends N8nClient to allow GET /credentials, GET /credentials/schema/{type}, POST /credentials admin; POST /workflows and PUT /workflows/{id} operator. instance_guard becomes same-task reentrant, letting root hold source+target guards in sorted order over a promotion while nested service calls reuse them. Provision accepts expected_hash and rejects a changed validated secret immediately before sending. Mapping deletion uses these same pair guards.

## Transformation worker interface

Pure transform.py exports fingerprint(value)->SHA256 deterministic JSON; prepare(workflow:dict,credential_map:dict[str,str],subworkflow_map:dict[str,str])->dict {workflow: writable JSON, required_credentials:[{id,type,name}], mapped:[...], missing:[...], collisions:[...], warnings:[...]}. Read node.credentials blocks, substitute IDs only there; reject malformed or ambiguous source IDs/types. Remap literal executeWorkflow node parameters.workflowId (string or resource-locator value) only with explicit subworkflow_map; dynamic/unknown references block via missing. Never substitute equal strings elsewhere. Top-level writable name,nodes,connections,settings only; preserve legitimate graph/node fields, omit source IDs/version/active/tags/meta/pinData/staticData. Unknown source-specific workflowId references in other node types block rather than guess. Missing credential maps stay reported; source workflow unmodified. Root fills secret-provisioning placeholders before calling prepare at deploy. Diff returned by root only as counts/names and hashes to avoid inline secrets.

## Root promotion behavior

POST /preflight source_instance_id,target_instance_id,workflow_id,credential_map={},secret_map={},subworkflow_map={}; distinct instances, operator (admin if provisioning), fetch source + persisted mapped target, inspect target credentials, schema/secret validation for provisioning, save encrypted preview with actor, expiry, source/target/config/mapping fingerprints. Returns preview_id, hashes, safe diff, mapped/missing/collisions/warnings, can_deploy. Explicit mappings trusted with diagnostic only if discovery unsupported. Existing target must be inactive. Secrets never returned, resolved values snapshotted as hashes.

POST /deploy preview_id,idempotency_key: atomically claim run and preview, return same result for same actor/key, reject key reuse for another preview. Re-fetch/revalidate snapshots before effects, persist stages before every credential/workflow write. Create or update mapped target inactive. Save previous target encrypted. Partial/unknown outcomes preserve residual credential IDs and recovery actions; never blindly retry. GET /runs and /runs/{id} safe status, POST /runs/{id}/reconcile optionally target_workflow_id (explicit identification for uncertain creates) verifies actual remote payload before completing mapping. POST /runs/{id}/activate verifies deployed target hash/bindings and inactive state, then records activation outcome separately. Recovery supports returning previous encrypted snapshot through authorized API and explicit restore only to unchanged inactive target; no distributed rollback claims.
