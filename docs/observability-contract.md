AGENTS.md remains the unchanged product specification. This contract assigns code ownership and concrete interfaces for the next verified unit.

Root owns database migration v4, machine-token middleware exemption, lifecycle retention, observability router/token/query storage, errors router and integration tests/docs. Parser worker owns ONLY backend/modules/observability/ingest.py and tests/test_otlp_parser.py. ## Ingestion parser

`parse_traces(body: bytes, content_type: str, content_encoding: str='identity')->dict` returns `{spans:[normalized dict],rejected_spans:int}`. Limits: raw/compressed 2 MiB, decompressed 8 MiB, 2000 spans/request, 16 KiB serialized safe attributes/span. Raise `IngestError(status:int,code:str,message:str)` with safe messages for malformed/unsupported/oversized input. JSON OTLP camelCase, traceId/spanId hex; protobuf official ExportTraceServiceRequest from installed opentelemetry.proto.collector.trace.v1.trace_service_pb2, IDs bytes to hex (not base64). JSON integers including nanosecond timestamps as strings accepted; ensure valid nonzero trace/span IDs length32/16, parent empty or valid16; start/end nonnegative end>=start; status UNSET/OK/ERROR normalized unset/ok/error. Dropped invalid individual spans => rejected count; malformed envelope or unsupported encoding => error. At most 2000 encountered spans, not just accepted. No arbitrary remote resource fetching.

Normalized keys (root supplies instance_id from token): trace_id,span_id,parent_id,name,kind,start_ns,end_ns,status,attributes_json (valid JSON string),workflow_id,workflow_name,execution_id,node_id,node_name,model,tokens_in,tokens_out,output_items,input_items. Extract documented/common n8n/gen_ai semantic attrs; model exact ID, never guess unknown provider/model. String repairs only detected reversible mojibake. Secret/prompt/input/output content attrs dropped by default; numeric token/item counts preserved. Oversized individual attributes dropped whole or replaced safe marker; never truncate JSON. Resource attributes may supply workflow/instance hints but cannot assign instance. No costs/classification guessed by parser.

## Classifier

Pure `classify(spans:list[dict], execution:dict|None, now_ns:int, grace_seconds:int=30, zero_output_nodes:set[str]|None=None)->list[dict]` returns per-span diagnostics `{span_id,health_status,error_type,error_summary,silent}`. No mutation. Confirmed span status error => error; execution status must terminal and grace elapsed before inferring missing or silent issues. Missing span alone => incomplete, not failed. Normal IF/Switch/filter/disabled/wait/branch absence must not generate errors. Execution resultData/runData node error can confirm continuation errors. Zero-output detection only opted-in node IDs, with evidence that node ran and sufficient item/history information; otherwise no silent error. Clamp/sanitize summaries to avoid leaking payloads. Preserve unknown as unknown. Tests must include wait, branches, late spans, confirmed continuation errors, no telemetry and zero-output opt-in.

## Pricing

Pure `calculate_cost(model:str|None,tokens_in:int|None,tokens_out:int|None,prices:dict,provider:str|None=None,cached_tokens:int|None=None,reasoning_tokens:int|None=None)->dict` => cost_usd (decimal string or None), pricing_source, price_timestamp, estimated bool. Exact model lookup only. price entry {input_per_million:decimal string,output_per_million:decimal string,cached_input_per_million:optional,reasoning_output_per_million:optional,source,updated_at}. Cached/reasoning counts are subsets of total input/output, prevent double-count, invalid counts => null. Explicit provider ollama => zero provider charge even unknown model; do not infer local merely from model name. Optional `select_prices(overrides,live,bundled)` merges precedence overrides>live>bundled; unsupported/unknown pricing stays None; no fuzzy model stripping.

## Root routes and persistence

observability manifest id observability, prefix /api/otel. Dedicated machine POST /v1/traces requires Bearer token (per-instance hashed random secret, not cookies/CSRF). Exempt ONLY exact POST /api/otel/v1/traces from session middleware; router fully authenticates machine token, content type/encoding/body limits and rate/concurrency before decoding. Token admin routes POST /tokens JSON {instance_id,name}, GET /tokens?instance_id, DELETE /tokens/{id}; plaintext token returned once, hash stored with FK instance cascade. Revalidate token inside batch transaction, token/instance revocation prevents in-flight insert. JSON response partialSuccess or protobuf ExportTraceServiceResponse matching request media type.

Schema v4 root adds telemetry_tokens(id PK,instance_id FK,name,token_hash UNIQUE,created_at,revoked_at), price_book(model PK,value_json), execution_cursors(key PK,value_json), adds otel_spans.cost_exact TEXT/pricing_json TEXT. Existing otel_spans keys retained and unique instance/trace/span deduplicated. Batch inserts atomically, safe redacted stored attrs; machine instance wins over forged resource attributes. Errors table add status default open, resolved_at. Admin retention PUT /retention {days:1..365}; default7 saved in documents, startup/periodic cleanup spans+errors; no retention by client-provided future timestamps.

GET /traces?instance_id optional&limit&before cursor => grouped trace summaries scoped by instance+trace. GET /traces/{trace_id}?instance_id required => waterfall spans, exact costs/unknown totals. GET /summary => real counts. GET /prices, admin PUT and DELETE /prices/{model:path} explicit rate override (a new price also prices AI steps still waiting for one); unknown costs remain null. POST /traces/{trace_id}/usage?instance_id reads AI token usage from the run's n8n execution, once per finished run. Root classification refresh POST /classify?instance_id&execution_id fetches execution once, grace and evidence guards; error triage GET /api/errors list filters, POST /{id}/resolve operator. No invented production metrics or synthetic error successes. Provider price sync added only after secure bounded fetch path and last-known-good behavior verified; track unfinished pieces explicitly.
