# Fleet connectivity work unit

Full scope remains in AGENTS.md. This unit implements n8n_proxy (instances, connectivity, workflows, executions, activation/deactivation and execution deletion); credential promotion and UI remain subsequent units. Reference API: n8n@2.19.0 public API YAML; verify compatibility by read-only endpoint probes, never claim permissions from a version string.

## Shared client / worker ownership

Worker owns ONLY backend/modules/n8n_proxy/client.py and tests/test_n8n_client.py. Root owns __init__, manifest, router, route tests, lifecycle changes, docs and progress. No DB migration needed; instances schema already exists.

N8nClient(request).request(instance_id: str, method: str, path: str, **kwargs) -> dict. Internal path is relative (e.g. '/workflows', '/workflows/123/activate'). Only fixed workflow/execution read routes, workflow activation/deactivation and execution deletion allowed this unit; no arbitrary proxy. Only params and json kwargs accepted; callers cannot override URL/headers/auth/cookies/follow_redirects. GET requires viewer, mutations operator. Current role/session revalidated with DB transaction immediately before issuing request, after instance lock acquired. Require explicit instance_id; no globally active target fallback. Fixed /api/v1 prefix, stored base URL may contain subpath, no query/fragment/userinfo. API key only X-N8N-API-KEY on this request; never set shared client headers. Use app.state.http streaming with raw/compressed response ceiling 4 MiB, identity encoding preferred and reject nonidentity, total wait 35s, generic redacted errors. No automatic retries, no redirects. Successful JSON must be object; no secret key/ciphertext echoed to responses/errors. Reject control characters in API keys at registration (root); client defends corrupted stored values too.

Map upstream 401/403 -> 502 code upstream_auth_failed/upstream_forbidden (do not log local user out); 404->404 upstream_not_found; 429->503 upstream_rate_limited; other non2xx read->502 upstream_error. Transport read failure->502 upstream_unavailable; timeout read->504 upstream_timeout. Mutation timeout/network/5xx/malformed-success/oversized-success -> 502 or504 upstream_outcome_unknown (must reconcile before retry). Definitely rejected mutation 400/404/409/422 -> corresponding status with safe generic codes/messages. Upstream Location/Set-Cookie and raw error bodies never forwarded.

`instance_guard(request,instance_id)` async context manager uses app.state.instance_locks (WeakValueDictionary[str, asyncio.Lock], created in main lifespan) to serialize config changes and remote requests for same instance without blocking other instances. Root PATCH/DELETE acquire this guard; client handles own request guard, so routes must not double-lock client calls. Under guard, query instance snapshot and current role in short DB transaction; do not hold DB lock over network. Snapshot once for URL/key so concurrent edits cannot mix them. Configuration remove never deletes remote resources.

## Root-owned API

Prefix /api/n8n_proxy:
- GET/POST /instances; GET/PATCH/DELETE /instances/{instance_id}. Admin changes; viewers see id/name/url/is_active/created_at/api_key_configured, never ciphertext/key. IDs UUID hex. Creation accepts name,url,api_key; validates http(s) base (no reserved address literals, encoded traversal, userinfo/query/fragment), normalization trailing slash removed. PATCH optional name/url/api_key, at least one nonnull field. Do not treat is_active as security enable switch; it's legacy selection metadata only.
- POST /instances/{instance_id}/probe; reads /workflows?limit=1 and /executions?limit=1&includeData=false independently. Returns reachable and workflow_read/execution_read supported|unavailable|forbidden, diagnostics, checked_at. No guessed version or mutation-scope claims. Admin only, CSRF and rate limit. Persist last safe probe record in documents for UI.
- GET /workflows?instance_id=&limit=25&cursor=&active=&name= (cursor max2048 opaque). Return data,next_cursor (map nextCursor), add instance_id to envelope. Read-only list excludes pinned data.
- GET /workflows/{id}?instance_id= returns workflow object, instance_id; detail enables later editor. Never alter graph here.
- POST /workflows/{id}/activate and /deactivate with required query instance_id. Operator, CSRF, audit intent before network and outcome afterward. Return upstream object with instance_id. Do not reroute or retry deprecated endpoint automatically.
- GET /executions?instance_id=&limit=25&cursor=&workflow_id=&status= (error|success|waiting|running|canceled|new|unknown supported according pinned contract). Forward only accepted fields, includeData=false. GET /executions/{id}?instance_id= calls includeData=true to inspect runData. DELETE /executions/{id}?instance_id= operator+audit, no retries.
- GET /health fleet summary: bounded parallel read-only workflow/execution probe, safe per-instance failure status without failing whole response. Require viewer; throttle polling. It must not mutate workflow state. Returning healthy means read API answered, not that executions are successful.

Tests: real FastAPI/auth/db/vault through ASGI, httpx MockTransport only at n8n network boundary. Cover encrypted CRUD/restart, invalid URL/key, RBAC/CSRF, concurrent same-ID workflows on two hosts with correct isolated API keys, pagination, API failures, viewer blocked before outbound mutation, audit intent/outcome, deleted target no request, key rotation, guarded config vs request, response/timeout limits, fleet partial health. No live n8n mutation during checks.
