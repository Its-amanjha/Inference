# Inference

## Platform

web

## Product Purpose

Self-hosted n8n fleet control, workflow promotion, execution observability and AI orchestration. The complete requirements remain in AGENTS.md; verified progress remains in IMPLEMENTATION.md.

## Users

Viewer, operator and administrator roles. Operators inspect executions, investigate anomalies and manage workflows; administrators manage connections, accounts and infrastructure.

## Capabilities and Constraints

FastAPI with native HTML/CSS/ES modules, no frontend build toolchain. Preserve all fourteen views, explicit instance targets, authorization and approval gates. Show actual API results and distinguish incomplete telemetry from confirmed failures. Never fabricate metrics.

## Brand Commitments

User-selected name: Inference. Tagline: Execution Anomaly System. September 14 reference: Flowmapp white blueprint desk with one blue pen, adapted for operational dashboard density. This replaces previous visual branding, not the core feature specification.

## Operating Context

Fleet overview, error investigation, workflow management, promotion, traces and AI costs, assistant approvals, instances, Docker, notes, backups, secrets and settings.

## Evidence on Hand

Existing API-backed frontend and local browser smoke fixtures. Live n8n, provider and S3 interoperability are separately unverified in the progress ledger.

## Accessibility & Inclusion

Keyboard navigation, visible focus, responsive mobile access, reduced motion and concise interface text. Optional external fonts have local system fallbacks.

## Current design assumptions

Anomaly-first overview and direct implementation follow the supplied dashboard brief; optional questions were sent during research. No permanent image/code workflow default has been selected.
