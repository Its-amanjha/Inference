# UI audit and repair — 2026-09-22

Scope: all 14 routes at 1440 and 390 px, Light/Dark/n8n themes; separate delayed
API, retained-data/429, native-picker keyboard, reduced-motion and Docker states.
This is a scoped engineering audit, not a complete WCAG certification.

## Findings addressed
- Shared icons were partial and hand-drawn: replaced the shared set with 46 local
  Lucide SVG definitions (release 0.468.0), retaining text/ARIA names and licenses.
- Browser-native selects lacked theme styling: progressive base-select styling,
  160ms picker/disclosure transitions, keyboard semantics and native fallback.
- Notes stretched an empty list to editor height: columns now align at their tops.
- Empty message placeholders consumed page gaps: hide empty top-level containers.
- Assistant disclosures had inconsistent spacing: matching inset disclosure cards.
- Docker absence looked like a broken remote connection: explicit local-engine
  explanation, unavailable provisioning, refresh recovery; unrelated 500s remain alerts.
- Loading bars touched panel edges and repeated scope text: inset skeletons,
  four metric placeholders, concise visible labels, full accessible status text.
- A slow fleet scan delayed all dashboard sections: each response now paints its
  own section independently. Refresh errors keep previous successful content.
- All-instance executions showed loading despite making no request: immediately
  show the instance-selection prompt instead.

## Verification
- 84 route/viewport/theme combinations: no horizontal overflow or page errors.
- Keyboard instance selection, six Settings navigation icons, reduced motion,
  and bounded empty Notes column verified in the final sweep.
- Delayed dashboard API: findings become visible while metrics remain pending;
  metric loading padding >=16px; 429 preserves content. All three themes/two widths.
- Full browser suite: 18 PASS, exit 0. The header-icon assertion now distinguishes
  three title icons and three link arrows, all decorative to assistive technology.
- Backend: 897 passed, 11 skipped, 1 warning in 290.03s. No backend changes.
- All 30 JavaScript modules parse using node --check on temporary .mjs copies.
- All verification servers used temporary data and free loopback ports, not 3000.

## Detector findings and remaining limits
The Impeccable detector reported seven warnings: six repeated Inter-font findings
and one existing 4px diagnostic border in decisions.css:101. Inter is explicitly
required by DESIGN.md, so those are intentional exceptions, not defects to replace.
The diagnostic border is a lower-priority style inconsistency, not a broken task.
Native animated select pickers depend on base-select support; unsupported browsers
retain functional platform-native selection. Existing diagnostic/backend errors
must be investigated rather than concealed with styling.
